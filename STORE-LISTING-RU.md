# VK Video Mirror — русская карточка

Разработчик / издатель: **Kardanio**

Версия: **1.0.0**

## Короткое описание

Отражайте видео VK по горизонтали одним нажатием, сохраняя положение кнопок плеера. Developed by Kardanio.

## Полное описание

VK Video Mirror — небольшое расширение для горизонтального отражения видео на сайтах VK. Нажмите иконку на панели браузера, чтобы включить зеркало в текущей вкладке. Нажмите ещё раз, чтобы вернуть исходный вид. Индикатор ON показывает, что режим включён.

Отражается изображение видео, а отдельные кнопки, таймлайн и слои управления сохраняют своё положение. Подходит, когда вам удобнее смотреть ролик в зеркальном виде.

Возможности:

- Переключение одним нажатием на иконку с символом видео и зеркальной осью.
- Независимый режим для каждой вкладки.
- Поддержка нескольких видео и вложенных открытых Shadow DOM.
- Автоматическое применение к динамически загруженному плееру.
- Работа при SPA-переходах и сохранение режима при обновлении страницы.
- Восстановление исходного масштаба видео после выключения.

Поддерживаемые сайты: vk.com, vkvideo.ru и vkvideo.com, включая поддомены. Расширение работает только с элементами video в открытом Shadow DOM. Обычный DOM и закрытые теневые деревья не поддерживаются. Текст, встроенный в изображение, отражается вместе с ним. При изменении плеера VK совместимость может потребовать обновления.

При включённом режиме расширение наблюдает за изменениями DOM и раз в секунду проверяет новые открытые теневые деревья. В фоновых вкладках обнаружение может занимать больше времени. После закрытия вкладки или перезапуска браузера режим сбрасывается.

Без рекламы, аналитики и передачи пользовательских данных разработчику. Обработка структуры страницы и CSS выполняется локально. Разрешение storage используется только для временного состояния вкладок. Доступ к сайтам нужен для поиска и отражения подходящих видео.
