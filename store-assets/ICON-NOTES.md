# Icon provenance

Developer brand: Kardanio. Extension: VK Video Mirror.

The master icon was generated with the built-in image_gen tool, then resized for production using alpha-preserving PNG export. It contains no VK logo or third-party wordmark. 16, 32 and 48 px versions use the same artwork; the 128 px version has a 96 px artwork area and 16 px transparent margins. No interlaced PNGs are used.

Final generation prompt:

> Use case: logo-brand. Create one professional browser extension app icon for VK Video Mirror, developer brand Kardanio. Square 1024x1024 raster master. A refined dark navy rounded square tile, with a bold centered white geometric video frame containing two opposing cyan and white play triangles separated by a vertical mirror axis, suggesting horizontal video reflection. Large simple silhouettes, precise optical balance, crisp edges and generous padding so legible at 16 pixels. Subtle blue/cyan accent, premium restrained flat graphic style. No text, no letters, no VK logo, no third-party trademarks, no mockups, no shadows outside the tile. Tile fills most of canvas with transparent corners. Output only the single finished icon.

The original generated raster is retained as `icon-master.png`. The production extension does not call image generation or include any related dependency.
